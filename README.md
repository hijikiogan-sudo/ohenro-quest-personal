# お遍路クエスト 個人テスト版 v0.13

四国八十八ヶ所の訪問記録と写真を、端末内で管理するPWAです。[アプリを開く](https://hijikiogan-sudo.github.io/ohenro-quest-personal/)

iPhoneのSafariで開き、共有メニューからホーム画面に追加できます。利用時にMacを起動する必要はありません。

## 写真アルバム

「写真」から全写真を開き、すべて・札所別・日付別・お気に入りで表示を切り替えられます。現在の巡礼、別の巡礼、全周回を選べます。写真を開くと、左右スワイプ、日付・メモ・札所の個別編集、お気に入り、個別書き出し、確認画面付き削除を利用できます。

札所を決めずに写真を追加し、あとから複数枚まとめて分類できます。写真を追加・分類するだけでは訪問済みにならず、XPも変わりません。

## 既存写真の更新とバックアップ

v0.6の写真がある場合は、アルバム更新前に全周回の旧形式ZIPをまとめて書き出し、保存できたことを確認してください。外側のZIPを展開すると、v0.6に読み込める周回ごとの旧形式ZIPが入っています。更新後は古いv0.6から写真保存領域を開けません。ほかの古いタブを閉じてから更新してください。訪問記録の保存方式は維持します。

設定から書き出す新しい写真ZIPはv2形式です。未分類・お気に入りを含み、読み込みにはv0.7以降が必要です。v0.7は旧形式ZIPも読み込めます。復元は現在の巡礼への追加で、重複は除外します。

写真ZIPは現在の巡礼の写真を保存します。訪問記録JSONには写真を含まないため、設定で両方を書き出してください。

## 保存上限・プライバシー

写真は長辺最大1600pxのJPEG、1枚1MiB以下に変換します。写真全体で200枚・100MiB、1回の追加は10枚までです。原本は別途保管してください。カメラで撮影した原本がiPhoneの写真アプリへ自動保存されるとは限りません。

写真・記録は端末とブラウザー内に保存し、GitHubや地図サービスへ送信しません。端末間の同期・認証・家族への自動共有はありません。ブラウザーのデータ削除、端末故障、容量不足などによる消失に備え、バックアップを別途保存してください。

## 地図と費用

初期表示はオリジナルのRPG風の冒険の地図です。装飾の山・森・船は実際の地形や経路を示しません。お寺アイコンと番号、県別表示、ライト／ダーク、道路地図の切り替えを利用できます。車の経路は各札所の「車ルート」から外部地図で確認します。

新しいアカウント、有料サービス、課金APIは使っていません。無料ホスティングや外部地図にも利用制限と提供条件があります。道路地図は通信が必要で、タイルの一括取得・オフライン保存は行いません。出典・条件はDATA-SOURCES.mdを参照してください。

実機iPhoneのカメラ、HEIC、タッチ操作、ホーム画面アプリと「ファイル」への保存は未確認です。家族・招待者との進捗比較、公開の走行情報投稿、実道路距離の巡礼計画、クラウド写真共有は今後の機能です。

## v0.10 今日の巡礼

保存した予定からホームで「今日の巡礼」を開始し、次の札所へのナビ・真言・写真・訪問登録をまとめて利用できます。今回だけの順番変更、見送りと復元、途中終了・直近の進行の再開に対応しています。進行中はホームの紹介部分を畳んで、次の札所を優先表示します。

進捗は開始日・明示的に再開した日の実際の訪問記録から表示し、過去日・日付不明・別周回の訪問を含めません。本日の記録数と今回全体の記録数を分け、ナビ・読経・写真だけでは訪問済みにしません。

進行状態は端末内の専用保存領域です。写真・訪問・予定の保存方式は維持し、新しい有料サービスはありません。現在の各バックアップには進行状態は含まれません。予定・訪問記録・写真は従来どおり個別にバックアップしてください。

99件の自動テスト、ブラウザーの開始から登録・見送り・終了と再開、390×844の表示、配信停止中の順番変更と保存・真言表示を確認しました。実機iPhoneのGPS・タッチ操作・機内モードは未確認です。


## v0.11 駐車場へのナビ（車遍路 STEP 1）

札所の詳細に「車でのアクセス」を追加しました。四国八十八ヶ所霊場会の札所案内で確認できた駐車場・駐車場から本堂までの距離・車両の制限・冬期の通行止め・ロープウェイを、出典と確認日付きで表示します（`data/car.json`、10札所）。情報がない札所は「まだ確認していない」と表示し、霊場会の案内へのリンクを出します。

駐車場に着いたら「現在地を駐車場として登録」で、その札所の駐車場の位置を端末内に保存できます（札所から3km以内・測位誤差50m以内）。登録すると次のように変わります。

- 札所詳細・ホームの「つぎの札所」・今日の巡礼・行き先予定のナビの行き先が、札所名＋住所ではなく駐車場の座標になる
- GPSチェックインが「本堂から誤差込み300m以内」に加えて「駐車場から誤差込み150m以内」でも通る（60番横峰寺のように駐車場から境内まで約500mある札所向け）

駐車場の位置は訪問記録・写真・予定とは別の保存領域です。設定の「駐車場の位置」からJSONで保存・復元できます（復元は追加のみ）。公式資料で座標を確認できた駐車場は `data/car.json` の `parkingPoints` に入れる仕組みですが、現時点で座標を確認できた出典はないため0件です。座標を推測では入れていません。

自動テスト：`node --test tests/car.test.mjs`（12件）。ブラウザーで390×844表示、横峰寺での駐車場登録→駐車場座標へのナビ→駐車場からのチェックイン→再読み込み後の保持→登録解除を、位置情報を模擬して確認しました。実機iPhoneのGPS・現地での測位は未確認です。


## v0.12 車の注意と自分の評価（車遍路 STEP 2）

- **一覧のラベルと絞り込み**：札所一覧に「冬期通行止めあり」「ロープウェイ」「駐車場から約500m」「費用がかかる」などのラベルを表示します。「車：要確認」「車：要確認なし」「自分の評価：注意以上」で絞り込めます。行き先予定の札所選び・めぐる順番にも同じラベルが出ます。
- **自分の評価（0 ふつう〜3 難所）**：札所詳細の「車でのアクセス」で、走ってみた感覚を4段階で記録できます。公式の格付けではなく、端末内だけに保存します。
- **行き先予定の「車の注意」**：出発予定日が冬期閉鎖の期間（横峰寺：霊場会の「12月下旬から2月いっぱい」を12/21〜2月末として扱い、「可能性」と表示）に当たるか、設定中の車が通行できない札所か、ロープウェイ札所か、駐車場から遠いか、自分の評価が「注意」以上かを表示します。出発日が未設定で閉鎖のある札所を含むときは日付の入力を促します。
- **今日の巡礼**：次の札所のラベルと、今日の日付で当たる注意を表示します。
- **乗っていく車の設定**：設定の「車の設定と駐車場」で軽自動車〜大型バスを選べます。現在、通行できない車種が公式に案内されているのは横峰寺（大型バス）だけです。
- **費用**：有料駐車場・志納金・ロープウェイ運賃がある札所を一覧にします。霊場会の案内に金額がない項目が多いため、合計金額は出していません。
- 駐車場と評価のバックアップはv2形式（v1も読み込み可）。保存領域はv0.11の駐車場の位置を残したまま更新します。

自動テスト：`node --test tests/car.test.mjs`（17件）。ブラウザーで、v0.11の保存領域からの更新で駐車場の位置が残ること、ラベル・絞り込み、評価の保存、大型バス設定、冬と夏の出発日での予定の注意を確認しました。地図上のラベル表示、札所間の移動時間の自動計算はまだです。


## v0.13 車メモと停車中モード（車遍路 STEP 3）

- **車メモ**：GPSチェックインを保存した直後に「ここまでの道はどうでしたか」を表示し、道幅・対向車とのすれ違い回数・バックで譲ったか・駐車場の混み具合・駐車場付近のトイレをタップで記録できます（すべて任意、「あとで」で閉じられます）。札所詳細の「車メモを書く」からいつでも書けます。同じ札所・同じ日のメモは1件にまとめて編集します。一覧から編集・削除（確認画面付き）ができます。
- **評価の目安**：車メモから自分の評価の目安（例：すれ違い6回以上・バックで譲った→3 難所）を表示し、「この評価にする」で反映できます。自動では変更しません。
- **停車中モード**：札所詳細と今日の巡礼から開ける、大きなボタンだけの画面です（ナビ／チェックイン／写真／車メモ）。運転中は操作しない前提で、画面の先頭に注意を表示します。
- 車メモは端末内だけに保存します。設定の「駐車場・評価・車メモを保存」でv3形式のJSONに書き出せます（v1・v2も読み込み可）。保存領域はv0.11・v0.12の駐車場と評価を残したまま更新します。

自動テスト：`node --test tests/car.test.mjs`（20件）。ブラウザーで、v0.12の保存領域からの更新、チェックイン直後の車メモ、同日メモの編集、評価の目安の反映、停車中モードとの行き来、削除、設定の件数表示を確認しました。実機iPhoneでの現地操作は未確認です。
