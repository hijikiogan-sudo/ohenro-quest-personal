# くるま遍路 個人テスト版 v0.46

（旧名：お遍路クエスト）

四国八十八ヶ所の訪問記録と写真を、端末内で管理するPWAです。[アプリを開く](https://hijikiogan-sudo.github.io/ohenro-quest-personal/)

iPhoneのSafariで開き、共有メニューからホーム画面に追加できます。利用時にMacを起動する必要はありません。

## 写真アルバム

「写真」から全写真を開き、すべて・札所別・日付別・お気に入りで表示を切り替えられます。現在の巡礼、別の巡礼、全周回を選べます。写真を開くと、左右スワイプ、日付・メモ・札所の個別編集、お気に入り、個別書き出し、確認画面付き削除を利用できます。

札所を決めずに写真を追加し、あとから複数枚まとめて分類できます。写真を追加・分類するだけでは訪問済みにならず、XPも変わりません。

## 既存写真の更新とバックアップ

v0.6の写真がある場合は、アルバム更新前に全周回の旧形式ZIPをまとめて書き出し、保存できたことを確認してください。外側のZIPを展開すると、v0.6に読み込める周回ごとの旧形式ZIPが入っています。更新後は古いv0.6から写真保存領域を開けません。ほかの古いタブを閉じてから更新してください。訪問記録の保存方式は維持します。

設定から書き出す新しい写真ZIPはv2形式です。未分類・お気に入りを含み、読み込みにはv0.7以降が必要です。v0.7は旧形式ZIPも読み込めます。復元は現在の巡礼への追加で、重複は除外します。

写真ZIPは現在の巡礼の写真を保存します。訪問記録JSONには写真を含まないため、設定で両方を書き出してください。

## 保存上限・プライバシー

写真は長辺最大1600pxのJPEG、1枚1MiB以下に変換します。写真の枚数・合計容量に上限はなく、端末の空き容量まで保存できます（v0.21から。空きが足りないときは保存せずにお知らせします）。1回の追加は10枚までです。バックアップのZIPは1つ4GB・65,535件までで、写真が非常に多いときはバックアップ・復元に時間とメモリを使います。原本は別途保管してください。カメラで撮影した原本がiPhoneの写真アプリへ自動保存されるとは限りません。

写真・記録は端末とブラウザー内に保存し、GitHubや地図サービスへ送信しません。端末間の同期・認証・家族への自動共有はありません。ブラウザーのデータ削除、端末故障、容量不足などによる消失に備え、バックアップを別途保存してください。

## 地図と費用

初期表示はオリジナルのRPG風の冒険の地図です。装飾の山・森・船は実際の地形や経路を示しません。お寺アイコンと番号、県別表示、ライト／ダーク、道路地図の切り替えを利用できます。車の経路は各札所の「車ルート」から外部地図で確認します。

新しいアカウント、有料サービス、課金APIは使っていません。無料ホスティングや外部地図にも利用制限と提供条件があります。道路地図は通信が必要で、タイルの一括取得・オフライン保存は行いません。出典・条件はDATA-SOURCES.mdを参照してください。

## v0.14 時間の目安と共有（車遍路 STEP 4・無料の範囲）

有料の経路APIやサーバーを使わず、端末内の計算とファイルの受け渡しだけで実現しています。

- **時間の目安**：行き先予定に、札所ごとの移動距離・移動時間・到着と出発の目安、移動の合計、最後の札所を出る（または帰着する）目安を表示します。移動は直線距離×1.4を平均速度（設定で時速30／35／40km）で割った概算です。駐車場の位置がある札所はその位置で計算します。
- **自分の実績を優先**：同じ日に続けて記録した自分のGPSチェックインの間隔を区間ごとに集め、実績がある区間は「実績から」の移動時間を使います（実績−前の札所の参拝予定時間）。山道で概算が短く出る区間ほど、実績が貯まると精度が上がります。
- **納経の受付時間**：到着の目安が8時〜17時（霊場会「お遍路の心得」の「基本的に午前8時より午後5時まで」）から外れる札所を表示します。
- **家族・友人と共有**：設定から、車メモ・自分の評価・駐車場の位置（選択式、既定は含めない）を共有ファイル（JSON）や文章にして、LINEやAirDropで渡せます。受け取った共有ファイルは自分の記録と分けて「共有されたメモ」として札所詳細に表示し、駐車場の位置は自分の登録や公式の座標がない札所でだけナビに使います。設定から外せます（20件まで）。
- 保存領域はv0.11〜v0.13の駐車場・評価・車メモを残したまま更新します。

自動テスト：`node --test tests/car.test.mjs`（27件）。ブラウザーで、v0.13の保存領域からの更新、共有ファイルの読み込み・書き出し・文章化、共有された駐車場でのナビ、7札所の予定の時間割と受付時間外の表示、参拝時間変更での再計算を確認しました。直線距離からの概算は山道で短く出ます（例：11番藤井寺→12番焼山寺が20分と表示されますが、実際の車の道のりはこれよりかなり長いことが知られています）。正確な所要時間はGoogleマップで確認してください。

- **予定の削除**：保存済みの行き先予定を開くと、「予定を保存」の下に「この予定を削除」が出ます。確認のあと、その予定だけを端末内から削除します。訪問記録・写真・今日の巡礼（予定のコピー）は消えません。別の画面で更新された予定は削除せず、開き直すよう案内します。
- **写真の上限をなくす**：写真の200枚・100MiBの上限をやめ、端末の空き容量まで保存できるようにしました。写真画面には上限の代わりに空き容量の目安を表示します。合わせて、写真ZIP（110MB・200枚まで）と「まとめてバックアップ」（600MBまで）の読み込みの上限を、ZIPの形式で扱える4GB・65,535件までに広げ、大きなZIPを作るときもファイルを8MBずつ読んで計算するようにしました。
- **版の表示**：スマートフォンの幅ではサイドバーが出ないため、設定の「自分の記録」にも「個人テスト版 · v0.21」を表示します。

## v0.20 使い勝手とゲーム要素の仕上げ

- **アプリ版への備え**：App Store版（Capacitor）などアプリの中で動いているときは、Service Workerを登録しません（ファイルを同梱するため不要で、登録に失敗して毎回お知らせが出るのを防ぐため）。設定に「出典とライセンス」を追加し、地図・札所の情報・お経・道路情報の出典と、Leafletのライセンス全文を1画面にまとめました。
- **現在地から近い未訪問の札所**：ホームの「つぎの札所」に「現在地から近い未訪問の札所を探す」を追加しました。ボタンを押したときだけ現在地を取得し、直線距離の近い順に3つ表示します（現在地は保存しません）。
- **文字の大きさ**：設定の表示モードに「文字の大きさ（標準／大きい／特大）」を追加しました。画面全体を拡大し、地図だけは元の倍率に戻して操作位置がずれないようにしています。まとめてバックアップに含まれます。
- **車タブを短く**：公式情報は先頭の2項目だけ見せて「ほかの情報」で開く形に、通行止めの確認リンクは折りたたみに、ボタンは2列にしました（12番焼山寺で約1,900px→約1,450px）。
- **XPとバッジの連動**：1寺100XPに加えて、バッジの段階1つにつき50XPが入ります。レベルは500XPごとです（10寺を回ると、以前はLv.3・1,000XP、今回からはバッジ分が加わります）。
- **振り返りカード**：バッジの欄に「振り返りカードをつくる」を追加しました。「今日」はその日にめぐった札所の一覧、「この巡礼」は四つの道場ごとの進み具合と、獲得した印を1枚の画像（1080×1350）にします。iPhoneでは共有メニューから写真アプリへの保存やLINEでの共有ができます。画像は端末内でつくり、外部には送りません。
