# お遍路クエスト 個人テスト版 v0.6

[アプリを開く](https://hijikiogan-sudo.github.io/ohenro-quest-personal/)

四国八十八ヶ所の訪問記録と札所別の写真アルバムを、手元の端末で管理するPWAです。iPhoneのSafariで開き、共有メニューからホーム画面に追加できます。利用時にMacを起動する必要はありません。

## 写真アルバム

札所の詳細からアルバムを開き、「写真を撮る」または「写真を選ぶ」で追加します。保存前に画像を確認し、任意の日付とメモを付けられます。写真の拡大、個別の書き出し、確認画面付きの削除に対応しています。

保存画像は長辺最大1600pxのJPEGに変換します。1枚1MiB以下、端末内で合計200枚・100MiBまでです。元の画質で残したい写真は別途保管してください。カメラで撮影した原本がiPhoneの写真アプリへ自動保存されるとは限りません。

写真はこのアプリを開いた端末・ブラウザ内に保存します。GitHubや地図サービスに写真・訪問記録を送信しません。端末間の同期や家族への自動共有、認証はありません。

## 地図

お寺の形のアイコンに札所番号を表示します。近い札所は「○寺」にまとめ、選択すると札所の一覧を開きます。拡大すると個々の札所を表示します。

背景は国土地理院の淡色地図とOpenStreetMapの道路地図を切り替えられます。ライト／ダークモード、県ごとの表示に対応しています。背景地図の読み込みには通信が必要です。地図タイルの一括取得やオフライン保存は行いません。

## バックアップ

設定から訪問記録のJSONと写真のZIPを、それぞれ書き出してください。訪問記録のJSONに写真は含まれません。写真ZIPは現在の巡礼の写真をまとめます。このアプリが作成したZIPのみ読み込めます（最大110MiB）。復元は現在の巡礼に追加する方式で、重複は除外します。

ブラウザのデータ削除、端末の故障や空き容量不足などで記録が失われる場合があります。保存先を確認し、定期的に両方をバックアップしてください。同じURLでもSafariと別のブラウザなどでは保存領域が異なります。

## 費用と制限

GitHub Pagesと公開地図を利用し、月額料金や課金API、新しい有料サービスは使っていません。無料サービスにも配信量などの利用制限や提供条件があります。出典・利用条件はDATA-SOURCES.mdを参照してください。

家族・招待者の進捗比較、全利用者向けの道路情報投稿は今後の機能です。

## 確認状況

訪問記録・写真保存・重複除外・容量制限・ZIPの整合性・地図アイコンなど、39件の自動テストを通過しました。ブラウザで画像の変換・再読込後の保存・配信停止中の写真保存・ZIPの書き出しと復元を確認しました。実機iPhoneのカメラ撮影、HEICの読み込み、ファイル保存は実機での確認が残っています。


## v0.6

最初に表示する位置図を、レトロRPG風の「冒険の地図」にしました。既存の海岸線と札所座標に、草原・森・山・船のオリジナルの装飾を重ねています。山・森・船は実際の地形や経路を示すものではありません。実際の経路は各札所の車ルートから確認してください。

地図のスタイルは「冒険の地図」「シンプルな位置図」「すっきり・淡色地図」「道路情報を詳しく」から選べます。選択は同じブラウザに保存します。ダークモードでも地図は明るい配色を維持します。県別の表示、番号付きのお寺、密集した札所の一覧選択を利用できます。

訪問記録と写真の保存方式、札所データは維持しています。39件の自動テスト、実ブラウザでの地図切り替え・札所選択・ダークモード、390×844の画面幅での表示を確認しました。実機iPhoneでの操作は未確認です。
