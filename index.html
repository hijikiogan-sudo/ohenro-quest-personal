まとめてバックアップ

訪問記録・写真・行き先予定・車のデータ・設定を、1つのファイルに保存・復元します。機種変更やブラウザのデータ消去に備えて、ときどき保存してください。

復元は新しい巡礼として追加し、今ある記録は消しません。下にある個別のバックアップも、これまでどおり使えます。

表示モード

自分の記録

写真の保管とバックアップ

「写真アルバム」または各札所の詳細から写真を追加できます。写真はこの端末だけに保存され、家族や外部へ共有しません。

写真の保存領域を確認しています…

写真・日付・メモ・お気に入り・未分類を含む新形式ZIPです（v0.7以降で復元）。旧形式のZIPも読み込めます。訪問記録のJSONには写真は含まれません。写真ZIPは今選んでいる巡礼へ、札所番号ごとに追加して復元します。ブラウザのデータ削除や機種変更に備え、両方を別の場所に保管してください。

訪問記録のバックアップ

写真以外の訪問記録をJSON形式で保存できます。ファイルには訪問日・メモが含まれるため、大切に保管してください。

バックアップを、周回ごとに新しい巡礼として復元できます。1巡礼のファイルは、現在の巡礼への追加も選べます。

既存の記録は置き換えません。読込前に復元方法を確認できます。GPS記録も手動記録として復元します。

ホーム画面に追加

iPhoneのSafari：共有ボタン →「ホーム画面に追加」。MacのSafari：「ファイル」→「Dockに追加」（対応版）。

初回は通信できる場所で開いてください。画面の準備ができれば、オフラインでも札所一覧・位置図・手動記録を利用できます。道路地図は通信が必要です。GPSにはHTTPSと端末の位置情報許可が必要です。

データと費用について

訪問記録・メモはこの端末のブラウザに保存します。GitHubへ送信しません。アプリの画面・プログラム・札所データはGitHub Pagesで公開されます。ルート案内を選ぶと外部地図アプリを開きます。

GitHub Pagesの無料枠を利用します。端末の通信料金は別です。無料配信にも容量・通信量などの制限があり、条件が変わる可能性があります。個人版にはログイン・家族との自動共有はありません。

札所データの出典・GPSの限界

名称・所在地は四国八十八ヶ所霊場会、座標は四国遍路日本遺産協議会の公開地図を照合（2026年10月14日）。現地測量・駐車場入口の座標ではありません。GPS記録は端末からの自己申告で、位置偽装を完全には検出できません。
